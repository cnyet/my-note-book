# Agents & Tools 列表页面重新设计

**创建日期**: 2026-03-10
**参考网站**: https://ai-bot.cn/
**状态**: ✅ 已批准

---

## 设计目标

将 Agents 和 Tools 页面的卡片布局从纵向改为横向列表式，采用统一的浅色背景和简洁的图标 + 标题 + 描述结构。

---

## 设计方案

### 布局变更

| 特性 | 当前设计 | 新设计 |
|------|---------|--------|
| 卡片方向 | 纵向（图标在上） | 横向（图标在左） |
| 背景样式 | 渐变色 (`from-indigo-500/20...`) | 统一浅色 (`bg-white/5`) |
| 内容层次 | 图标 + 标题 + 角色标签 + 描述 | 图标 + 标题 + 描述（基础版） |
| 卡片尺寸 | 大卡片 (~200px 高) | 紧凑列表项 (~100-120px 高) |

### 卡片结构

```
┌─────────────────────────────────────────────┐
│  ┌────┐                                     │
│  │图标│  标题（加粗，白色）                    │
│  └────┘  描述文字（灰色，一行或两行）          │
│                                    [箭头]    │
└─────────────────────────────────────────────┘
```

### 视觉规格

#### 卡片容器
- 尺寸：宽约 350-400px（自适应），高约 100-120px
- 背景：`bg-white/5` 或 `bg-slate-800/50`
- 边框：`border border-white/10`
- 圆角：`rounded-xl`
- 悬停：`border-indigo-500/40` + 上移 2-4px

#### 图标区域
- 尺寸：48x48px
- 容器：`rounded-xl bg-white/5 border border-white/10`
- 位置：卡片左侧
- 颜色：悬停时变为主题色（indigo-400）

#### 内容区域
- 标题：16-18px，font-bold，白色，悬停时 `text-indigo-400`
- 描述：13-14px，`text-slate-400`，leading-relaxed
- 布局：flex 纵向排列，gap-1

#### 箭头指示器
- 位置：右下角绝对定位
- 状态：默认隐藏，悬停时淡入
- 样式：`ArrowRight` 图标，`text-indigo-400`

### 网格配置

保持现有响应式网格配置：

**Agents 页面**:
```
xl: 5 列 | lg: 3 列 | sm: 2 列 | base: 1 列
```

**Tools 页面**:
```
lg: 3 列 | sm: 2 列 | base: 1 列
```

### 动画效果

| 动画 | 实现 |
|------|------|
| 进入动画 | Framer Motion stagger 淡入上移 |
| 悬停边框 | `transition-colors duration-300` |
| 卡片位移 | `translate-y` -2px 悬停 |
| 箭头淡入 | `opacity-0` → `opacity-100` |

## 实现注意事项

1. **移除不必要的元素**：
   - 移除状态指示器（右上角脉冲点）
   - 移除角色标签（`text-indigo-400 uppercase` 小标签）

2. **保持的功能**：
   - Loading 和 Error 状态
   - Framer Motion 动画
   - 响应式网格布局
   - 悬停交互效果

3. **简化内容**：
   - 只保留图标 + 标题 + 描述
   - 描述文字控制在 1-2 行内
