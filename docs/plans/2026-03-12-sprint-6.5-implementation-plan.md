# Sprint 6.5: 前端页面美化实施计划

> **For Claude:** REQUIRED SUB-SKILL: Use `superpowers:executing-plans` to implement this plan task-by-task.

**Goal:** 按照 n8n.io 和 ai-bot.cn 的布局风格，美化 Home、Agents、Tools、Labs、Blogs 五个页面

**Architecture:**
- 导航栏左右对齐改造，删除 Dashboard 按钮
- 统一所有 Section 的间距和容器宽度
- Footer 重构为全宽 4 列布局（n8n.io 风格）
- Agents/Tools 采用 6 列网格，Labs 采用 5 列网格
- 底部链接改为标签样式，8 列布局，固定在页面底部

**Tech Stack:** Next.js 15.5, React 19.1, Tailwind CSS 3.x, Framer Motion

**Design Doc:** `docs/planning/2026-03-12-sprint-6.5-frontend-beautification-design.md`

### Task 3: Footer 重构（n8n.io 风格）

**Files:**

- Create: `frontend/src/components/ui/HomeFooter.tsx`

**Steps:**

1. 创建 HomeFooter 组件
   ```tsx
   // frontend/src/components/ui/HomeFooter.tsx
   export function HomeFooter() {
     return (
       <footer className="w-full bg-void border-t border-white/10">
         <div className="max-w-7xl mx-auto px-4 sm:px-6 lg:px-8 py-12">
           {/* 4 列布局 */}
           <div className="grid grid-cols-2 md:grid-cols-4 gap-8">
             {/* Product */}
             <div>
               <h3 className="text-white font-semibold mb-4">Product</h3>
               <ul className="space-y-2">
                 <li><FooterLink href="#">Features</FooterLink></li>
                 <li><FooterLink href="#">Solutions</FooterLink></li>
                 <li><FooterLink href="#">Pricing</FooterLink></li>
                 <li><FooterLink href="#">Enterprise</FooterLink></li>
               </ul>
             </div>

             {/* Ecosystem */}
             <div>
               <h3 className="text-white font-semibold mb-4">Ecosystem</h3>
               <ul className="space-y-2">
                 <li><FooterLink href="#">Integrations</FooterLink></li>
                 <li><FooterLink href="#">Marketplace</FooterLink></li>
                 <li><FooterLink href="#">API Docs</FooterLink></li>
                 <li><FooterLink href="#">Community</FooterLink></li>
               </ul>
             </div>

             {/* Studio */}
             <div>
               <h3 className="text-white font-semibold mb-4">Studio</h3>
               <ul className="space-y-2">
                 <li><FooterLink href="#">Templates</FooterLink></li>
                 <li><FooterLink href="#">Components</FooterLink></li>
                 <li><FooterLink href="#">Examples</FooterLink></li>
                 <li><FooterLink href="#">Tutorials</FooterLink></li>
               </ul>
             </div>

             {/* Company */}
             <div>
               <h3 className="text-white font-semibold mb-4">Company</h3>
               <ul className="space-y-2">
                 <li><FooterLink href="#">About</FooterLink></li>
                 <li><FooterLink href="#">Careers</FooterLink></li>
                 <li><FooterLink href="#">Contact</FooterLink></li>
                 <li><FooterLink href="#">Press</FooterLink></li>
               </ul>
             </div>
           </div>

           {/* 底部版权信息 */}
           <div className="mt-12 pt-8 border-t border-white/10 flex justify-between items-center">
             <p className="text-gray-400 text-sm">
               © 2026 My-Note-Book. All rights reserved.
             </p>
             <div className="flex gap-4">
               <FooterLink href="#">Privacy</FooterLink>
               <FooterLink href="#">Terms</FooterLink>
               <FooterLink href="#">Cookies</FooterLink>
             </div>
           </div>
         </div>
       </footer>
     );
   }

   function FooterLink({ href, children }: { href: string; children: React.ReactNode }) {
     return (
       <li>
         <a
           href={href}
           className="text-gray-400 hover:text-white transition-colors text-sm"
         >
           {children}
         </a>
       </li>
     );
   }
   ```

2. 在首页引入 HomeFooter
   ```tsx
   import { HomeFooter } from '@/components/ui/HomeFooter';

   export default function HomePage() {
     return (
       <div className="min-h-screen flex flex-col">
         <Header />
         <main className="flex-1">
           <Hero />
           <Features />
           <Stats />
           <CTA />
         </main>
         <HomeFooter />
       </div>
     );
   }
   ```

3. 运行 TypeScript 检查
   ```bash
   cd frontend && npm run type-check
   ```

4. 提交
   ```bash
   git add frontend/src/components/ui/HomeFooter.tsx frontend/src/app/\(public\)/page.tsx
   git commit -m "feat(home): redesign footer with n8n.io style 4-column layout"
   ```

### Task 5: Agents 网格布局改造（6 列）

**Files:**
- Modify: `frontend/src/app/(public)/agents/page.tsx`

**Steps:**

1. 修改网格布局为 6 列
   ```tsx
   <div className="min-h-[600px] py-12">
     <div className="max-w-7xl mx-auto px-4 sm:px-6 lg:px-8">
       <div className="grid grid-cols-1 md:grid-cols-3 lg:grid-cols-6 gap-4">
         {AGENTS.map((agent) => (
           <AgentCard key={agent.id} agent={agent} />
         ))}
       </div>
     </div>
   </div>
   ```

2. 调整 AgentCard 组件尺寸适配 6 列布局
   ```tsx
   <div className="group relative bg-surface/60 backdrop-blur-xl rounded-xl
                   border border-white/5 overflow-hidden
                   hover:border-primary/20 hover:-translate-y-1
                   transition-all duration-300">
     <div className="p-4">
       {/* Icon */}
       <div className="w-12 h-12 mx-auto mb-3 rounded-lg bg-primary/10
                       flex items-center justify-center">
         <Icon className="w-6 h-6 text-primary" />
       </div>
       {/* Name */}
       <h3 className="text-sm font-semibold text-white text-center mb-1">
         {agent.name}
       </h3>
       {/* Role */}
       <p className="text-xs text-gray-400 text-center mb-3">
         {agent.role}
       </p>
       {/* Capabilities */}
       <div className="flex flex-wrap justify-center gap-1">
         {agent.capabilities.map((cap) => (
           <span
             key={cap}
             className="px-2 py-0.5 bg-gray-800/50 text-gray-400
                        text-xs rounded"
           >
             {cap}
           </span>
         ))}
       </div>
     </div>
   </div>
   ```

3. 运行 TypeScript 检查
   ```bash
   cd frontend && npm run type-check
   ```

4. 提交
   ```bash
   git add frontend/src/app/\(public\)/agents/page.tsx
   git commit -m "feat(agents): 6-column grid layout"
   ```
