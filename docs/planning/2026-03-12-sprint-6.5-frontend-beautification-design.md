## 设计概述

### 设计方向
**极简高端 × 赛博科技感混合风格**

- **极简主义**: 大量留白、精致排版、微妙动画
- **赛博科技**: 深色主题、渐变光晕、代码元素
- **核心理念**: "Refined Future" - 精致的未来感

## Home 页面设计

### 1. 导航栏改造
```
┌─────────────────────────────────────────────────────────────┐
│ [Logo]  Home  Agents  Tools  Labs  Blogs                   │
└─────────────────────────────────────────────────────────────┘
```
- **删除**: 右侧 "Dashboard" 按钮
- **布局**: 内容左右对齐（Logo 左对齐，导航项右对齐）
- **样式**: 玻璃态背景，固定在顶部

### 2. Section 间距统一
| Section | Padding |
|---------|---------|
| Hero | py-32 lg:py-40 |
| Features | py-32 lg:py-40 |
| Stats | py-32 lg:py-40 |
| CTA | py-32 lg:py-40 |

- **容器宽度**: 统一 `max-w-7xl mx-auto px-4`
- **间距一致性**: 所有 Section 使用相同的垂直间距

### 3. Footer 重构（n8n.io 风格）
```
┌─────────────────────────────────────────────────────────────────┐
│ Product          Ecosystem         Studio           Company     │
│ ├── Features     ├── Integrations  ├── Templates      ├── About  │
│ ├── Solutions    ├── Marketplace   ├── Components     ├── Careers│
│ ├── Pricing      ├── API Docs      ├── Examples       ├── Contact│
│ └── Enterprise   ├── Community     ├── Tutorials      ├── Press  │
├─────────────────────────────────────────────────────────────────┤
│ © 2026 My-Note-Book · Privacy · Terms · Cookie Settings        │
└─────────────────────────────────────────────────────────────────┘
```
- **全宽背景**: `w-full` 与屏幕等宽
- **4 列布局**: 响应式断点适配
- **社交链接**: 底部右侧

```jsx

                 transition-colors duration-200">
  Label Text
</span>
```

### 布局要求
| 属性 | 值 |
|------|-----|
| 每行数量 | 8 列 |
| 对齐 | 居中对齐 |
| 位置 | 固定在页面底部 |
| 间距 | `gap-3` |

## 技术实现规范

### 网格系统
```jsx
// Agents/Tools: 6 列
<div className="grid grid-cols-1 md:grid-cols-3 lg:grid-cols-6 gap-4">

// Labs: 5 列
<div className="grid grid-cols-1 md:grid-cols-2 lg:grid-cols-5 gap-4">

// Blogs: 3 列（文章卡片）
<div className="grid grid-cols-1 md:grid-cols-2 lg:grid-cols-3 gap-6">
```

### 最小高度容器
```jsx
<div className="min-h-[600px] py-12">
  {/* 内容区域 */}
</div>
```

### 固定底部 FooterLinks
```jsx
<div className="mt-auto border-t border-gray-800 pt-8">
  <div className="flex flex-wrap justify-center gap-3">
    {/* 标签链接 */}
  </div>
</div>
```
